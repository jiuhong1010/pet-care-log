# 毛毛档案 · pet-care-log

给养猫养狗的人记照护变化、疫苗、驱虫、体重、用药和看病记录的小工具。打开就能用，不注册、不登录，数据只存在你自己的浏览器里。

## 为什么做这个

宠物的数字产品大多是审美类的（肖像、纪念画、周边），**功能性的记录工具几乎不成品类**。而疫苗和驱虫这件事本身是周期性的、忘了有后果的、且大量人正在用手机备忘录和 Excel 凑合。

这个项目在验证一个具体假设：**养宠物的人正在用备忘录/表格记这些事，并且觉得麻烦。** 如果假设错了，方向就该换。

## 已经能用的功能

- **多只宠物** — 切换、头像、按生日自动算年龄
- **疫苗与驱虫** — 记一次接种日期和间隔，自动推算下次时间；内置猫三联、狂犬、狗四联、体内外驱虫等预设，按宠物种类过滤
- **到期提醒** — 逾期 / 30 天内到期分色显示，放在首屏最上方；同名项目只看最近一次，不会一直显示去年的逾期
- **体重曲线** — 手写 SVG 折线图，自动算出比第一次重了还是轻了
- **用药记录** — 药名、用法、起止日期，在吃的会标出来
- **看病记录** — 重点是「医生说了什么」，换医院时不用凭记忆复述
- **健康事件时间线** — 发现一点变化就开始一段事件，按事实记录食欲、精神、呕吐、排便等，不要求先判断疾病
- **看诊包** — 自动整理异常观察、最近体重、当前用药和想问医生的问题，可打印成看诊卡
- **用药接力** — 记录今天是否完成、完成时间和照护人，方便家里轮流照顾
- **本地照片** — 观察可附现场照片，二进制只保存在浏览器 IndexedDB，结构化备份仍由用户主动导出
- **插画照护轨迹** — 首页把最近观察、当前用药和到期事项放进一条可点击的动态曲线
- **导出备份** — 一键导出 JSON，包含全部结构化照护记录

## 技术选择与取舍

| 选择 | 原因 |
|---|---|
| localStorage + IndexedDB，无后端 | 结构化记录轻量保存在 localStorage，现场照片单独放 IndexedDB；没有账号系统、没有服务器成本，也不碰用户数据 |
| 手写 SVG 折线图，不引图表库 | 引 recharts 会让首屏体积翻倍，而这个页面要在小红书的链接里秒开。当前 gzip 后 56 kB |
| 本地日历日计算，不用 UTC | 疫苗到期只关心哪一天。用 UTC 或直接减时间戳会在时区和夏令时边界上差一天 |
| Phosphor 单一图标入口 | 设置、返回、关闭等操作符号保持统一；宠物身份和照护业务使用独立插画 |
| 系统字体栈，不加载 Web 字体 | `system-ui` 在 Apple 设备上就是 SF Pro，零下载成本，且这是苹果风的前提 |
| Vite + React + TS + Tailwind | 单人维护，类型安全省下的调试时间比写类型的时间多 |

## 视觉规范：安静的照护台

采用移动优先、插画与真实数据联动的照护界面：

- **语义色**：systemBlue / Green / Red / Orange 等，深浅两套通过 CSS 变量随 `prefers-color-scheme` 切换
- **背景分层**：晨雾底色 + 白色内容表面，薄荷与天空蓝只服务照护路径
- **文字层级**：label 不透明、secondaryLabel 60%、tertiaryLabel 30%
- **排版**：Dynamic Type 默认尺寸，body 17/22、largeTitle 34/41，含 Apple 规范的 tracking 值
- **布局**：14px 卡片圆角、16px 左右外边距、最小点击尺寸 44px；手机使用底部四入口导航
- **动效**：`cubic-bezier(0.32, 0.72, 0, 1)` 近似 iOS 的弹层曲线；尊重 `prefers-reduced-motion`

**深色模式跟随系统自动切换**，没有手动开关——苹果用户的预期就是跟随系统。

**已知的边界**：

- 换设备或清浏览器缓存会丢数据，所以内置了导出备份并在页脚提示
- 无痕模式下 localStorage 不可写，此时页面顶部会显示提示而不是静默失败
- 没有真正的推送提醒（需要后端或 PWA + 通知权限）。目前是打开页面才看到到期项——这也是下一步最该验证的需求：用户是否真的需要主动提醒
